# AI Chatbot using Flask + Gemini API

A simple AI chatbot built with **Python, Flask, JavaScript, HTML, CSS, and the Google Gemini API**.

This project demonstrates how a web application can send user messages from a frontend to a Flask backend, process them using Gemini, and display the AI-generated response in the browser.

## Features

- 💬 Interactive chatbot interface
- 🤖 AI-generated responses using Google Gemini
- 🐍 Flask backend
- 🌐 HTML and CSS frontend
- ⚡ JavaScript for sending messages without reloading the page
- 🔐 API key stored securely using environment variables
- 📱 Simple and responsive chat interface
- ⌨️ Send messages using the Enter key
